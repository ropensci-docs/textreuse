# Extract candidate document pairs from a token index

Extract candidate document pairs from a token index

## Usage

``` r
token_index_candidates(index)
```

## Arguments

- index:

  A `textreuse_token_index` object returned by
  [`token_index`](https://docs.ropensci.org/textreuse/reference/token_index.md).

## Value

A `textreuse_candidates` data frame.
